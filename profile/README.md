# Schreibtischhelden

[schreibtischhelden.github.io](https://schreibtischhelden.github.io)

Wir bauen schlanke, wartbare Software: statische Websites ohne Datenbank, kleine Bibliotheken mit sauberem Output und Werkzeuge, die man selbst betreiben kann. Unsere Projekte sind Open Source.

## Projekte

### 📌 openLitfass – deine eigene digitale Litfaßsäule

Ein schlanker, statischer Veranstaltungskalender für einen Kiez, ein Dorf, einen Verein oder Eventtage. Termine werden automatisch aus RSS, JSON-APIs, iCal, HTML und WordPress-Kalendern gesammelt. Heraus kommt eine statische Website ohne Datenbank und ohne API-Server. → [openlitfass.org](https://openlitfass.org)

| Repo | Beschreibung |
|---|---|
| [`openlitfass`](https://github.com/schreibtischhelden/openlitfass) | Kern in Go: Fetch, Site-Build, Server und Frontend |
| [`openlitfass-configui`](https://github.com/schreibtischhelden/openlitfass-configui) | Konfiguration im Browser erstellen → [config.openlitfass.org](https://config.openlitfass.org) |
| [`openlitfass-docs`](https://github.com/schreibtischhelden/openlitfass-docs) | Dokumentation → [docs.openlitfass.org](https://docs.openlitfass.org) |

Beispiel-Instanz: [weissens.ee](https://weissens.ee/) für Berlin-Weißensee.
